# Dokumen UMS Health Innovation Hackathon 2026

> Basis pengetahuan untuk memilih tantangan dan menyusun proposal UMS HI Hackathon 2026.
> Diperbarui 14 Oktober 2026. **Batas pengajuan final: 20 Oktober 2026, 23.59 WIB.**

## Struktur dokumen

```
docs/
├── README.md                      ← indeks ini: struktur, sumber, tanggal penting
├── 01-kebutuhan-mitra.md          ← ringkasan 4 mitra & 6 tantangan, temuan situs, perbandingan
├── 02-ketentuan-program.md        ← tim, kategori, rubrik penilaian, jadwal, pendanaan
├── 03-template-proposal.md        ← template resmi, petunjuk isian per bagian, checklist
├── 04-peran-tim.md                ← rincian tugas 4 koordinator, penyesuaian per tantangan
└── mitra/                         ← detail per mitra
    ├── rs-ums-ar-fachrudin.md     ← RS-01
    ├── cv-arbain.md               ← ARB-01, ARB-02
    ├── pt-lkpi.md                 ← LKPI-01, LKPI-02
    └── dpm-drpps-ums.md           ← UMS-01 (termasuk analisis UMS Innovation Hub)
```

**Urutan baca yang disarankan:**

1. [01 · Kebutuhan Mitra](01-kebutuhan-mitra.md) — pilih tantangan.
2. File mitra yang dipilih di [mitra/](mitra/) — pahami kebutuhan secara rinci.
3. [02 · Ketentuan Program](02-ketentuan-program.md) — pahami aturan tim dan cara penilaian.
4. [04 · Peran Tim](04-peran-tim.md) — bagi peran dan tugas anggota.
5. [03 · Template Proposal](03-template-proposal.md) — tulis proposal dan cek sebelum unggah.

**Folder kerja tim** ada di luar `docs/`, di [proyek/](../proyek/README.md): satu folder per tantangan, sudah diisi awal dari riset sekunder. Isinya 6 fase design thinking (Empathize, Define, Ideate, Prototype, Test, Implement) dan draf proposal.

```
proyek/
├── README.md                ← indeks 6 proyek
├── _template/               ← kerangka kosong + panduan metode tiap fase
├── rs-01/  arb-01/  arb-02/  lkpi-01/  lkpi-02/  ums-01/
│   ├── README.md            ← identitas, alur fase, status, konvensi penandaan
│   ├── 01-empathize.md … 06-implement.md
│   └── proposal-draf.md     ← draf substansi, dipetakan ke file fase
```

Setiap file mitra berisi: profil mitra, temuan dari situs mitra, rincian tantangan (latar belakang, kondisi saat ini, pengguna, arah solusi, keluaran, batasan, indikator, dukungan mitra), catatan untuk penyusun proposal, dan pertanyaan untuk mitra.
