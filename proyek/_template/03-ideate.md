> Penanggung jawab utama: koordinator teknis, melibatkan seluruh tim

**Tujuan:** menghasilkan sebanyak mungkin kemungkinan solusi untuk masalah yang sudah dirumuskan, baru kemudian menilai dan memilih — jangan langsung berhenti di ide pertama.

Alur: **Problem statement → HMW → Competitive audit → Crazy 8s → Pilih → Goal statement**

---

## 1. How Might We (HMW)

Ubah problem statement dari [02-define.md](02-define.md) menjadi pertanyaan "Bagaimana kita bisa ...?". Buat sebanyak mungkin, dari berbagai sudut:

| Sudut | Teknik | Pertanyaan HMW |
|---|---|---|
| Perkuat yang baik | Ubah hal negatif jadi positif | Bagaimana kita bisa ... |
| Jelajahi kebalikannya | Pertimbangkan kebalikannya | |
| Ubah status quo | Ubah prosesnya | |
| Pecah masalah | Bagi jadi bagian kecil | |
| Hilangkan yang buruk | Hapus hal negatifnya sama sekali | |
| Ubah kata sifat | Kata sifat negatif → positif | |
| Pertanyakan asumsi | Tantang proses yang dianggap wajib | |
| Analogi | Bandingkan dengan pengalaman/sumber lain | |

HMW yang baik: cukup terbuka untuk banyak solusi, cukup fokus untuk masalah spesifik.
