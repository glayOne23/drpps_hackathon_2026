**Prioritas sebelum batas proposal (20 Okt):** fase 1–3 dalam bentuk ringkas, ditambah bukti awal dari fase 4 dan rencana dari fase 5–6. Riset sekunder di `docs/` sudah mencakup sebagian besar fase Empathize. Fase 4–6 dikerjakan penuh setelah lolos seleksi.

Fase tidak harus linear. Kembali ke fase sebelumnya bila hasil uji atau masukan mitra mengubah pemahaman masalah.

## Konvensi penandaan

Setiap klaim di file fase diberi salah satu tanda, sesuai prinsip Pedoman ("pisahkan hasil, asumsi, dan target"):

| Tanda | Arti |
|---|---|
| `[sumber: X]` | Dari sumber sekunder: pernyataan mitra, laman resmi, atau situs mitra (kode X sesuai [daftar sumber](../../docs/README.md#sumber), mis. `[sumber: S]` = sosialisasi). Bisa dipercaya sebagai titik awal, tetapi belum dikonfirmasi tim langsung ke pengguna |
| `[asumsi]` | Dugaan atau kesimpulan tim; belum dikonfirmasi pengguna/mitra |
| `[tervalidasi: sumber, tanggal]` | Sudah dikonfirmasi lewat wawancara, observasi, data mitra, atau uji |
| `[target]` | Hasil yang ingin dicapai, belum terjadi |

## Kerangka yang dipakai

- 5 fase Empathize → Define → Ideate → Prototype → Test: Google UX Design Certificate (`referensi/Google UX Design Professional Certificate.md`).
- Fase Implement dan pengelompokan Understand–Explore–Materialize: NN/g Design Thinking.
- Unsur yang dipinjam per fase: *need statement* dan checklist Implement dari Stanford Biodesign; jadwal hackathon dari Design Sprint; evaluasi formatif dari IEC 62366-1 (alat kesehatan); siklus hipotesis dari Lean UX.
