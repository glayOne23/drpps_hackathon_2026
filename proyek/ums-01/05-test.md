## 1. Rencana uji (draf)

| Pertanyaan | Isian |
|---|---|
| Siapa | Tim Hilirisasi DPM (2–3), inovator dari 3–5 produk uji, 2–3 perwakilan industri |
| Apa | Relevansi rekomendasi, ketepatan peta celah, kualitas *product brief*, kegunaan |
| Di mana / kapan | Saat hackathon dengan data katalog; saat pendampingan pada forum *business matching* nyata |
| Mengapa | Validasi H1–H4 ([02-define.md](02-define.md#7-hypothesis-statements)); syarat diuji dengan 3–5 produk nyata `[sumber: W]` |
| Bagaimana | Penilaian relevansi oleh pakar; perbandingan waktu manual vs otomatis; uji tugas |

## 2. Metrik

| Metrik | Cara ukur | Target |
|---|---|---|
| Relevansi pencocokan | Tim hilirisasi/industri menilai top-5 rekomendasi per produk (relevan/tidak) | ≥ [ ]% relevan |
| Ketepatan peta celah | Inovator/Sentra KI menilai checklist kesiapan per produk | Disetujui untuk ≥ [ ] produk |
| Waktu *product brief* | Menit per produk, manual vs otomatis | Turun |
| Kualitas *product brief* | Penilaian industri (jelas, lengkap, meyakinkan) | ≥ [ ] dari 5 |
| Kegunaan | % tugas selesai tanpa bantuan | ≥ [ ]% |

## 3. Skenario uji (draf)

| No | Skenario | Persona | Hipotesis | Kriteria lulus |
|---|---|---|---|---|
| S1 | Tim hilirisasi meminta rekomendasi mitra untuk ENSIKOL | P-A | H1 | ≥ [ ] dari 5 rekomendasi relevan |
| S2 | Inovator melihat peta celah produknya | P-B | H3 | Paham langkah berikutnya |
| S3 | Tim hilirisasi membuat *product brief* untuk forum | P-A | H2 | Lebih cepat dari manual |
| S4 | Industri membaca *product brief* | P-C | H2 | Menilai cukup untuk memutuskan pertemuan |
| S5 | Tim hilirisasi memperbarui status prospek | P-A | H4 | Tanpa bantuan |
